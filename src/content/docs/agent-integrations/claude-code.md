# 接入 Claude Code

## 安装 Claude Code

参考[Claude 官方文档](https://code.claude.com/docs/zh-CN/quickstart)

## 配置环境变量

Linux/macOS

```sh
export ANTHROPIC_BASE_URL="https://api.aiproxy.shop"
export ANTHROPIC_AUTH_TOKEN="<your-api-key>"
export ANTHROPIC_MODEL="anthropic/claude-opus-4.8"
```

Windows

```sh
$env:ANTHROPIC_BASE_URL="https://api.aiproxy.shop"
$env:ANTHROPIC_AUTH_TOKEN="<your-api-key>"
$env:ANTHROPIC_MODEL="anthropic/claude-opus-4.8"
```
